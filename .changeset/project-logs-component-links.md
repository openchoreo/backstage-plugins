On a project's Logs tab, each entry's component name links to that component's
Logs tab, keeping the environment, time range, log levels, search, sort and
live mode. For a component with release lines, the link opens the line that
wrote the entry: an entry from a release line selects that line, and a
main-line entry opens the component's main line. Clicking the name opens the
component's logs instead of expanding the row.
